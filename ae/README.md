# ICSE 2027 artifact

The fixed GitHub software snapshot is [v0.0-icse27-ae](https://github.com/Veri-Q/ConQEC/releases/tag/v0.0-icse27-ae).
The associated Zenodo version DOI is
[10.5281/zenodo.24523358](https://doi.org/10.5281/zenodo.24523358). The DOI has
been reserved. The draft will become publicly accessible upon publication.

Use this repository's [quick start](../README.md#quick-start) to try the core
software without the archival datasets. For paper reproduction, download the
archive identified by the version DOI, verify its checksums and follow its
README. The archive contains the full RQ1–RQ4 evidence and derivation scripts,
including formal case and query logs and the drivers used for the corrected
RQ1 timing campaign. Its documentation identifies the archived reconstructions
and the workloads that can be rerun.

The GitHub tag records the software snapshot. The Zenodo version DOI identifies
the archival deposit that includes the experimental evidence.
